Cómo lo pensamos

Armamos un sitio con tres juegos (cartas, dados y trivia) y una tabla de posiciones, con la temática de Wonderland. Usamos HTML y CSS para el diseño, JavaScript para la lógica de cada juego y localStorage para guardar el nombre del jugador y los récords. En la trivia usamos la API Open Trivia DB para traer las categorías. Trabajamos en equipo en GitHub y documentamos todo en el README.
